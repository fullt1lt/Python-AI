## 25 типичных задач на собеседовании

Ниже собраны задачи, которые хорошо проверяют понимание базового Python, циклов, строк, списков, словарей, функций, поиска и алгоритмического мышления.

Задачи расположены примерно от простых к более сложным.

---

### 1. Чётное или нечётное число

Напишите функцию, которая принимает число и определяет, является оно чётным или нечётным.

```python
is_even(10)
```

Результат:

```text
True
```

```python
is_even(7)
```

Результат:

```text
False
```

## Как работать с задачами

При решении каждой задачи старайтесь придерживаться одного порядка:

```text
Читаем условие
        ↓
Определяем входные данные
        ↓
Определяем ожидаемый результат
        ↓
Продумываем несколько примеров
        ↓
Пишем самое простое решение
        ↓
Проверяем крайние случаи
        ↓
Оцениваем сложность
        ↓
При необходимости улучшаем решение
```

На собеседовании важно не только получить правильный результат.

Не менее важно уметь объяснить:

- почему решение работает;
- какие структуры данных использованы;
- какие крайние случаи возможны;
- какая временная сложность решения;
- можно ли сделать решение проще или быстрее.
